Lire les notes Sur une fiche, passe la souris sur une note pour voir son résumé. Clique sur la note pour garder le résumé ouvert, puis sur « Pourquoi cette note ? » pour le détail. Un clic ailleurs le referme. L'étoile marque la meilleure note parmi les versions dans ton profil. En notation poussée, le résumé dit si les paramètres d'encodage sont vérifiés (publiés dans le MediaInfo) ou non publiés (note d'un encodage moyen, qui peut se tromper dans un sens ou dans l'autre). Le chiffre est la note sur 100. La couleur ne suit pas la note : elle dit si la version correspond à ton profil. Vert : dans ton profil Jaune : il manque un critère Rouge : trop lourd pour ton profil Gris : deux critères manquent, ou plus Ton équipement : une version que ton écran ou ton appareil ne lit pas (réponse « Non ») est notée × 0,5, et le résumé le dit en rouge ; « Je ne sais pas » : × 0,9, en orange avec « ? ». Une fois par version. « 3D » remplace la note d'une version 3D quand ton écran ne lit pas la 3D (ou n'est pas renseigné). À la première visite d'une fiche, les notes apparaissent au fil de la lecture (une version toutes les 0,7 s), dès que le format de l'image du film est connu (en notation poussée : quand toutes les versions sont lues) ; l'étoile vient quand tout est lu. Les visites suivantes sont immédiates. « – » : fiche sans MediaInfo, donc sans note. « Bonus » : torrent de bonus seuls, sans le film, donc sans note.
